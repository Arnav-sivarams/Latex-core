# Professor demo assets

> **If testing SMTP delivery, replace these three addresses with inboxes you can actually access before importing.**

The fixtures describe two Students, one Faculty Mentor, one CSE programme, and one Paper Team with exactly one Writer Leader. All names, IDs, and addresses are synthetic.

Run `./examples/professor-demo/make-demo-assets.sh` from the repository root. It creates ignored ZIP files under `examples/professor-demo/dist/` for the Main Content Template and Front Matter Pack. Import all seven CSV files together through **Admin → Imports** using **Add**.
