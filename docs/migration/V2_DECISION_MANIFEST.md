# V2 Decision Manifest Contract

Later migration work will require reviewed human decisions. C2 does not create completed decisions or infer decision makers. It defines the future tab-separated `migration-decisions.tsv` contract only.

## Schema

```text
decision_type	entity_id	selected_action	target_id	reason	decided_by	decision_reference
```

| Column | Contract |
| --- | --- |
| `decision_type` | Controlled decision category. |
| `entity_id` | Stable legacy identifier, or the documented composite identifier for a change set or path policy. |
| `selected_action` | Explicit action from the category's future allow-list. Never inferred from a blank value. |
| `target_id` | Stable destination identifier when the action transfers or converts an entity; blank only when the selected action does not need one. |
| `reason` | Human rationale sufficient for later audit. |
| `decided_by` | Authenticated decision-maker identifier, not a display name alone. |
| `decision_reference` | Ticket, approval, or other durable review reference. |

Initial `decision_type` values are:

- `USER_ROLE`
- `PERSONAL_PAPER_OWNER`
- `RESEARCH_GROUP`
- `PRIVATE_DRAFT`
- `ZERO_PROJECT_TEAM`
- `POLICY_MAPPING`

Future apply tooling must validate each category's selected action, required target shape, referenced source entity, decision-maker authority, and uniqueness. It must reject missing, duplicate, unknown, malformed, or incompatible decisions rather than choosing defaults.

Examples below illustrate shape only and are deliberately incomplete—not approved decisions:

```text
decision_type	entity_id	selected_action	target_id	reason	decided_by	decision_reference
USER_ROLE	<legacy-user-id>	<writer|mentor|admin|archive>		<human rationale>	<admin-user-id>	<approval-reference>
PRIVATE_DRAFT	<project-id>:<user-id>	<merge|export|archive|reject>	<optional target>	<human rationale>	<admin-user-id>	<approval-reference>
```

No manifest is generated by C2 because doing so could be mistaken for completed authorization. Future checkpoints must consume a separately reviewed manifest and retain an auditable link between each decision and its migration result.
